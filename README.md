"Without My Supervision" — one out-of-office reply for the make.fun
bounty `u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8`
("Funniest One-Line Out-of-Office Reply").

> I'm away until Monday; urgent matters may proceed without my supervision, as they so often do anyway.

The line is 101 characters. It keeps the real away-message frame —
away until Monday, a note on urgent matters — and puts the laugh
inside that urgent-matters clause: work may proceed without the
sender's supervision, as it so often does anyway. It stands alone
with no signature and avoids the usual beach, inbox and
limited-access lines.

## The program

`main.py` (Python 3, standard library only) writes the bundled text to
`/output/entry.txt`, verifying it first: UTF-8, 1 to 160 characters,
not only white space, a single line. It uses no network, and both
runs write identical bytes.

## Run it

```sh
python3 main.py /tmp/entry.txt
```
